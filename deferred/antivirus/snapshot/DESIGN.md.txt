# Premium Remodel workspace

Visual thesis: a calm, crisp workspace in warm white, slate, and the existing Premium Remodel blue, with the company's own project photography giving each job a recognizable place.

Content plan: the primary workspace opens on projects, with a compact operational summary, searchable project gallery, and status filters. Each project opens into its brief, job master sheet, tasks, files, and updates. Persistent navigation contains company contacts, invitations, and account settings.

Interaction thesis: project cards enter with a short stagger; hovering a project reveals its opening action and gently lifts the photograph; dialogs and tabs transition quickly to preserve context. Reduced-motion preferences remove animation.

Brand and photography are downloaded from premiumremodel.com with the owner's authorization. All sample clients, addresses, task assignments, and prices are fictional. No sample records are written to the company database. The public sample workspace stores its changes only in the current browser.

Calendar visual thesis: a quiet month grid in the existing blue palette, with compact task and project-date markers and a readable agenda.
Calendar content plan: month navigation and filters, the date grid, selected-day details, then upcoming work. The project calendar uses the same component with the project fixed.
Calendar interaction thesis: date selection highlights its agenda, calendar items open the existing editors, and selected-day task creation carries the date into the form. Existing button and tab transitions preserve context and respect reduced-motion preferences.

Upcoming visual thesis: a calm, compact work list with clear time labels and light section dividers in Premium Remodel blue.
Upcoming content plan: one Upcoming destination in both navigation levels, List/Calendar switch, shared search/type/status/project filters, grouped work, and one Add work action.
Upcoming interaction thesis: view switching keeps filters in place, work rows open the same editor, and calendar day selection carries the date into creation. Quick hover/focus transitions and the existing modal motion preserve context.

Generate visual thesis: a restrained photo workspace with warm material swatches, a compact control column and one dominant renovation preview.
Generate content plan: photo capture/upload, style and model controls, then an original/renovated comparison with download. The company model preference lives in Settings.
Generate interaction thesis: selected styles gain a clear outline, the result fades in, and a keyboard-accessible comparison slider reveals the renovation. Reduced-motion preferences remove transitions.

Activity visual thesis: a calm chronological feed with clear actor names, precise payment amounts, and small type icons in the existing workspace palette.
Activity content plan: a Log activity action, project/type/search filters, event details and attachment links. Project views include two compact totals for logged incoming and subcontractor payments.
Activity interaction thesis: a focused modal adapts fields to the activity type, filters narrow the feed, and task completion immediately adds an entry. Existing focus and modal transitions respect reduced motion.

Overview activity visual thesis: five compact rows beneath the statistics, using the existing typography and light dividers to make current work easy to scan.
Overview activity content plan: Latest activity, the five most recent events across all projects with actor, details, project and time, and a persistent View all activity button. The workspace sidebar has no separate Activity destination.
Overview activity interaction thesis: rows open the project's Activity tab, View all activity opens the full feed with a Back to overview action, and existing focus/hover transitions keep navigation clear.

Dark mode visual thesis: deep slate surfaces, soft white text and clear blue actions, retaining project photography and the red/yellow/green status meanings.
Dark mode content plan: a quick theme toggle in the top bar and Light, Dark or System in Settings; the same preference applies to login, projects, calendars and dialogs.
Dark mode interaction thesis: theme changes apply immediately, system mode follows device changes, and the saved preference is applied before first paint and shared between browser tabs.

Quotes and collections visual thesis: compact quote rows and one clear scope price, with a restrained payment progress bar and precise dollar amounts in both themes.
Quotes and collections content plan: Quotes holds draft, sent and declined leads; each quote contains contact details, scope pricing and files. Project overview adds collected payments, remaining dollars and percentages, and a receipt list. A historical price mismatch is a warning inside the scope total box.
Quotes and collections interaction thesis: accepting a quote moves the same record and its scope/files into Projects. Log payment opens the existing activity form with Check selected; payment history and balances update together. Existing focus and reduced-motion behavior apply.

Team map visual thesis: one dominant street map with clear teammate markers, a compact last-updated list and the existing Premium Remodel blue.
Team map content plan: a visible sharing control, administrator map, update time and accuracy per teammate, and home-screen installation help in Settings. Sharing is voluntary, lasts while the app is in use, and has no route history.
Team map interaction thesis: selecting a teammate focuses the map; sharing status stays visible while navigating; start/stop feedback is immediate and map focus movement respects reduced motion. Installation uses the browser prompt where supported and concise phone instructions elsewhere.

Job notes visual thesis: a simple text composer and chronological notes, using the existing quiet surfaces and team avatars.
Job notes content plan: a Notes tab within each project, an Add note action, and newest-first notes with author and date; notes also appear in the activity feed.
Job notes interaction thesis: drafts survive tab changes within the job, saving has immediate feedback, and existing tab and button transitions respect reduced motion.

Note attachments: a compact Attach photo or file control, selected filenames, and small image previews within saved notes. Each attachment uses the same project file record shown in Photos & files. Opening a photo uses the existing modal and failed saves retain uploaded file references for retry.

File security visual thesis: use the existing quiet Settings section and compact text statuses, with no new dashboard chrome.
File security content plan: show scanner configuration, scanned/pending/blocked counts, and a clear unavailable state in place of unscanned previews or download links.
File security interaction thesis: uploads show scanning progress through the existing busy state, failures retain the draft, and blocked files remain visible for administrator review without opening their contents.
